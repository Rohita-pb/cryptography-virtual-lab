Theory

Data Encryption Standard (DES) Algorithm

DES is a symmetric-key block cipher in which the same secret key is used for encryption and decryption. DES processes data in 64-bit blocks and accepts a 64-bit key, of which 56 bits are effective cryptographic key bits and 8 bits are used for parity checking.

DES uses a 16-round Feistel cipher network. Each round splits the 64-bit data block into 32-bit left ($L$) and right ($R$) halves, expands the right half to 48 bits, XORs it with a 48-bit round subkey, passes it through eight non-linear S-boxes to produce 32 bits, permutes it via a P-box, and XORs the result with the left half.

DES Cipher Operation:
Encryption: C = DES(K, P)
Decryption: P = DES-1(K, C)

Double DES

Double DES applies the DES encryption operation twice sequentially using two independent keys, K1 and K2.

Double DES Encryption:
C = E(K2, E(K1, P))
Double DES Decryption:
P = D(K1, D(K2, C))

Security Consideration: Despite using $2 \times 56 = 112$ key bits, Double DES is vulnerable to the Meet-in-the-Middle (MitM) attack, which reduces its effective computational complexity to approximately $2^{57}$ operations rather than $2^{112}$.

Triple DES (3-Key EDE) Mathematical Formulation

Triple DES was developed to prevent the Meet-in-the-Middle vulnerability of Double DES. It applies DES three consecutive times using the standard EDE (Encrypt–Decrypt–Encrypt) construction with three independent 56-bit keys: K1, K2, and K3.

Standard Triple DES (3-Key) Equations
Triple DES Encryption
C = E(K3, D(K2, E(K1, P)))
Triple DES Decryption
P = D(K1, E(K2, D(K3, C)))
Explanation of Mathematical Notation:
  • P = Plaintext block (64 bits)
  • C = Ciphertext block (64 bits)
  • E(K, X) = DES encryption of data block X using key K
  • D(K, X) = DES decryption of data block X using key K
  • K1, K2, K3 = The three independent DES keys (56 effective bits each, totaling 168 key bits)
Step-by-Step Encryption Process:
1
Stage 1 (Encrypt): Encrypt Plaintext P with Key K1:
X1 = E(K1, P)
2
Stage 2 (Decrypt): Decrypt intermediate result X1 with Key K2:
X2 = D(K2, X1) = D(K2, E(K1, P))
3
Stage 3 (Encrypt): Encrypt intermediate result X2 with Key K3:
C = E(K3, X2) = E(K3, D(K2, E(K1, P)))
Step-by-Step Decryption Process:
1
Stage 1 (Decrypt): Decrypt Ciphertext C with Key K3:
Y1 = D(K3, C)
2
Stage 2 (Encrypt): Encrypt intermediate result Y1 with Key K2:
Y2 = E(K2, Y1) = E(K2, D(K3, C))
3
Stage 3 (Decrypt): Decrypt intermediate result Y2 with Key K1:
P = D(K1, Y2) = D(K1, E(K2, D(K3, C)))
Why Encrypt–Decrypt–Encrypt (EDE)? When all three keys are identical ($K1 = K2 = K3$), the middle decryption stage exactly cancels the first encryption stage: D(K1, E(K1, P)) = P, resulting in C = E(K1, P). This provides complete backward compatibility with legacy single DES hardware.

Triple DES Key Configurations

Mode Key Sequence Operation Effective Key Length
1 Key K1, K1, K1 E(K1) → D(K1) → E(K1) 56 bits (Single DES equivalent)
2 Keys K1, K2, K1 E(K1) → D(K2) → E(K1) 112 bits
3 Keys K1, K2, K3 E(K1) → D(K2) → E(K3) 168 bits (112 bits against MitM)

DES S-Box (Substitution Box S1)

Purpose of S-Boxes in DES

In the Data Encryption Standard, S-boxes (Substitution boxes) serve as the only non-linear components in the cipher. While permutations and key additions are purely linear operations, S-boxes provide Claude Shannon's core cryptographic property of Confusion—obscuring algebraic dependencies between plaintext, key bits, and ciphertext bits.

DES utilizes eight distinct S-boxes ($S_1$ through $S_8$). In each round, a 48-bit expanded block is split into eight 6-bit vectors. Each 6-bit block enters an S-box, which compresses it into a 4-bit block ($8 \times 6\text{ bits} = 48\text{ bits} \to 8 \times 4\text{ bits} = 32\text{ bits}$).

Mapping: How 6-Bit Input Converts to 4-Bit Output

Each S-box is organized as a 4-row by 16-column matrix containing values from 0 to 15. Given any 6-bit binary input vector: b1 b2 b3 b4 b5 b6

Row Determination (2 Bits)
Outer Bits: b1 and b6

The first bit (MSB) and the sixth bit (LSB) are combined into a 2-bit binary number: (b1b6)2. This value specifies the Row index (Row 0, 1, 2, or 3).

Column Determination (4 Bits)
Middle Bits: b2 b3 b4 b5

The four middle bits are combined into a 4-bit binary number: (b2b3b4b5)2. This value specifies the Column index (Columns 0 to 15).

Procedure

Double DES Procedure

  1. Enter the plaintext message.
  2. Enter Key 1 and Key 2 in 16-character hexadecimal format.
  3. Click the Encrypt button.
  4. Observe the first DES encryption using Key 1 (intermediate output X1).
  5. Observe the second DES encryption using Key 2 (ciphertext C).
  6. Click Decrypt.
  7. Observe the reverse operations: Stage 1 decrypts with Key 2, and Stage 2 decrypts with Key 1 to recover the plaintext.

Triple DES Procedure

  1. Enter the plaintext message.
  2. Select 1-key, 2-key, or 3-key mode.
  3. Enter the required DES keys in hexadecimal format.
  4. Click Encrypt.
  5. Observe the three sequential DES stages using the standard EDE structure: E(K1) → D(K2) → E(K3).
  6. Click Decrypt.
  7. Verify that reverse decryption: D(K3) → E(K2) → D(K1) recovers the original plaintext message.

⚠ Security Note

DES and 2-Key Triple DES are legacy cryptographic algorithms deprecated by NIST (SP 800-131A). 3-Key Triple DES is also retired for new applications due to sweet32 block collisions (64-bit block limit). They are demonstrated here for academic and historical cryptanalysis purposes. Modern production architectures mandate AES-128 / AES-256 (Advanced Encryption Standard).
